# 开发预览说明：不用先打安装包也能调界面

## 核心结论

**可以、也应该先预览。** 安装包（`.exe`）只在界面和功能都满意后再打。

| 阶段 | 命令 | 能做什么 |
|------|------|----------|
| **开发预览** | `npm run dev` | 打开真实桌面窗口，改代码后多数情况**自动刷新** |
| **打包安装** | `npm run dist` | 生成安装包；改界面后需**重新打包**才进 exe |

---

## 界面主要改哪些文件？

本项目界面不是「一堆独立 HTML 页面」，而是 **React 组件 + CSS**：

| 你想改… | 主要文件 |
|---------|----------|
| 颜色、间距、按钮样式 | `src/renderer/src/index.css` |
| 三个 Tab 整体布局 | `src/renderer/src/App.tsx` |
| 记录表单 | `src/renderer/src/components/RecordForm.tsx` |
| 折线图页 | `src/renderer/src/components/DayChart.tsx` |
| 设置页 | `src/renderer/src/components/SettingsPage.tsx` |
| 跟进弹窗 | `src/renderer/src/components/NudgePanel.tsx` |
| 情绪词列表 | `src/renderer/src/data/emotions.ts` |
| 页面外壳（仅一个挂载点） | `src/renderer/index.html` |

改完保存 → 开发模式下窗口通常会**热更新**；没刷新就关掉窗口再执行一次 `npm run dev`。

---

## 在本机第一次预览（复制到终端）

在项目文件夹 `项目` 里打开 **PowerShell** 或 **CMD**：

```powershell
cd "C:\Users\25234\Pictures\项目"
npm install
npm run dev
```

若 `npm` 提示找不到命令，用完整路径：

```powershell
& "C:\Program Files\nodejs\npm.cmd" install
& "C:\Program Files\nodejs\npm.cmd" run dev
```

> 本项目使用 **JSON 本地文件** 存数据，**不需要** `npm rebuild better-sqlite3`，也不必为数据库单独装 VS/Python。

成功后会弹出 **「情绪记录」** 桌面窗口，和以后安装包里的界面是同一套代码。

---

## 和「只改 HTML」的区别

- `index.html` 里只有一个 `<div id="root"></motion>`，真正界面由 React 画出来。
- 调样式优先改 **`index.css`**；改结构和文字改 **`.tsx` 组件**。
- 这样仍然比在 exe 里改要方便得多：开发模式秒级见效。

---

## 什么时候才需要 `npm run dist`？

- 界面、提醒、记录功能都试过后；
- 需要发给别的电脑安装，或希望自己电脑上「像普通软件一样」安装时。

之后若又改了界面，再执行一次 `npm run dist` 即可得到新版安装包。
